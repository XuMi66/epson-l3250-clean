# epson-l3250-clean

爱普生 L3250 的「清洗喷头」要么真的洗了，要么什么都没做——而驱动在这两种情况下显示得一模一样。这个工具把差别变成可测量的数字。

它做三件事：

1. **测量一次清洗到底有没有效。** 在清洗前后各读一次打印机 EEPROM 里的计数，比较差值：墨有没有真的被抽进废墨垫，有数字可看，不用靠猜。
2. **告诉你维护指令为什么失败。** `phase=never_started`（打印机收了指令却没动）和 `phase=done`（真做了，但墨没进喷头）是两个完全不同的病，官方驱动统一显示「已完成」。
3. **读写废墨垫计数器。** 大多数「点了清洗没反应」其实卡在这里：废墨垫计数一到上限，打印机会拒绝一切维护指令、连打印都停。写入前自动备份，写完回读校验。

EEPROM 读写由 [EWR](https://github.com/RxNaison/Epson-Waste-Reset) v1.6.0（Apache-2.0）完成，本项目是它上面的诊断与图形层，负责把结果翻译成人话。

仅 Windows。Python 3.10 以上，不需要装任何第三方包。

## 「清洗没用」其实是四种病

| # | 实际情况 | 怎么看出来 | 怎么治 |
|---|---|---|---|
| A | **被拒。** 打印机处在报错态（`0x10 SERVICE REQUEST` / `0x2C CARTRIDGE OVERFLOW` = 废墨垫计数满、`0x05 INK OUT` 缺墨、缺纸），清洗指令根本没发进去 | 工具报 `blocked`，附打印机自己的错误码 | 清零废墨计数器后拔电源重启；缺墨就先加墨 |
| B | **收了指令但没执行。** 打印机回了 OK，状态却一直停在待机。个别固件不认自家这条维护指令 | `phase=never_started` | 加 `--print-data` 重发（改走打印数据通道） |
| C | **执行了，但墨没动。** 固件说做完了，废墨垫计数不动、清洗计数也不动——泵没吸力，或者帽站密封不严 | `phase=done` 且计数零增量 | 物理排查：看管路气泡、用注射器回抽、擦帽站密封圈 |
| D | **执行了，墨也动了，喷嘴图还是断。** 墨到了废墨垫，没进喷头 | `phase=done` 且计数有增量 | 喷头干堵或管路进气：浸润闷头，静置后再充墨 |

A 和 B 是软件问题，C 和 D 得动手。先让工具告诉你属于哪一类。

## 安装

1. 装 Python 3.10+（安装时勾选 "Add python.exe to PATH"）。
2. 把 EWR v1.6.0 下载解压到脚本旁边的 `EWR\` 目录：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\setup-ewr.ps1
   ```

   或者自己下 [EWR-v1.6.0-win.zip](https://github.com/RxNaison/Epson-Waste-Reset/releases/download/v1.6.0/EWR-v1.6.0-win.zip) 解压到当前目录，最后应该有 `EWR\ewr.exe` 和 `EWR\database.json`。
3. 打印机 USB 线直插电脑（别走集线器），开机，关掉爱普生官方软件和其他清零工具。

不接打印机也能先自检：

```powershell
python l3250_clean.py --check
```

## 使用

### 图形界面

```powershell
python l3250_clean.py
```

先点 **「清洗诊断」**：它会做一次正常清洗并前后测量，结论写进 `诊断报告.txt`。

### 命令行

```powershell
python l3250_diag.py                  # 测一次正常清洗
python l3250_diag.py --print-data     # 打印机收了指令却不动时，换通道重发
python l3250_diag.py --level strong   # 加量，测量方式不变
python l3250_diag.py --selftest       # 不接打印机，验证判定逻辑
```

一次真实运行的输出长这样：

```
[1/4] 读取打印机状态 …
    型号 Epson L3250  状态 IDLE  无报错
    墨量 Black 82%  Cyan 64%  Magenta 71%  Yellow 88%
    废墨垫 Main Pad 11%（700/6346）  Platen 1%（40/3416）

[2/4] 读取清洗相关计数（清洗前的基线）…
    manual_cleaning_counter=10  power_cleaning_counter=2

[3/4] 发送清洗指令（正常清洗）…
    ok   phase=done  route=factory  started=True  92s

[4/4] 清洗后回读计数 …
    manual_cleaning_counter=11  power_cleaning_counter=2

==============================================================
结论：清洗确实执行了，墨水进了废墨垫
依据：
  · 废墨垫 Main Pad：700 -> 742（+42）
  · manual_cleaning_counter：10 -> 11（+1）
```

退出码：`0` 洗到了墨；`3` 诊断完成但问题在物理层；其余表示指令没跑完。

## 结论怎么读

| 结论 | 意思 | 接着做什么 |
|---|---|---|
| `pads_full` | 废墨垫计数满，打印机自锁 | 先清零，拔电源 30 秒再开机，重跑 |
| `ink_low` | 墨仓低于 1/3 | 加墨，静置 10 分钟，再充墨 |
| `blocked` / `printer_error` | 打印机在报别的错 | 面板上把错消掉，重跑 |
| `ignored` | 指令被接收，打印机没动 | `--print-data`，或按住停止键 5 秒 |
| `command_failed` | 发出去了但被拒/中断 | `--print-data`，换 USB 口和线 |
| `timeout` | 还在做（打印机会自己做完） | 等 10 分钟别拔电，再测一次 |
| `done_with_ink` | 这轮清洗是真的做了 | 打喷嘴检查图：变好→再洗一次；没变→走物理排查 |
| `done_no_ink` | 说完成了，但计数一点没动 | 泵或帽站，走物理排查 |
| `done_no_meter` | 这台读不到可对照的计数 | 看喷嘴图，再走物理排查 |

## 物理排查（真正能通喷头的那部分）

从上往下做，每做完一条就重跑一次工具，看计数动没动。

1. **看墨管。** 掀开上盖，四根透明墨管通到喷头。里面若有气泡或空段，说明墨根本没到喷头——再洗一百次也没用。
2. **用注射器回抽。** 把废墨管从废墨垫上拔下来，接注射器缓慢回抽 2–3 ml，同时让打印机做一次清洗，看有没有墨出来。抽完立刻插回去擦干净。
3. **闷喷头。** 把喷头移开帽站，用喷头清洗液（或温水）浸湿无纺布叠厚，垫在帽站位置，让喷头压上去闷 20–30 分钟。
4. **擦帽站密封圈。** 棉签蘸清洗液擦橡胶圈和刮片，擦完吸干。`done_no_ink` 最常见的成因就是这圈老化压不严，泵抽的全是空气。
5. **静置，再充墨。** 关机放 8–12 小时，做一次强力充墨（`--level power`），之后再关机静置 12 小时。爱普生对充墨后的 12 小时静置也是这么要求的，省掉这一步就是白烧半瓶墨。
6. **还不行？** 喷头干堵报废或墨泵组件损坏，该送修了。

几条别把自己搞得更惨的规矩：

- 连续清洗最多 2–3 轮，然后停几个小时。不停顿地连洗，正是空气进入墨路的常见原因。
- 任何一个墨仓低于 1/3 就别洗，那是在往喷头里打空气。
- 刚连洗三轮的机器不要马上做强力充墨；充墨过程中绝不能拔电。

---

## 关于废墨计数器清零

清零不等于把废墨垫里的墨弄走了，它只是告诉打印机「垫子又空了」。如果垫子真的饱和，墨早晚会从机器底部漏出来。印量大的话，该换垫子，或者接一个外接废墨瓶。工具在写入前会自动备份原值，写完后回读校验，确保真的写进去了。
